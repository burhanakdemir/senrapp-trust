# Responsible disclosure

SENRAPP welcomes good-faith security research on the official products listed in [SECURITY.md](./SECURITY.md).

## How to report

1. Mail **hello@senrapp.com** with subject `[SECURITY]`.  
2. Describe the issue clearly; attach a minimal PoC if possible.  
3. Give us a reasonable window to investigate before any public write-up.  
4. We prefer coordinated disclosure; we do not pay a formal bug bounty today (acknowledgements may be offered for significant, valid reports).

## What we publish

- Public security summary: https://senrapp.com/guvenlik.html  
- Operator identity: https://senrapp.com/hakkimizda.html  
- `security.txt`: https://senrapp.com/.well-known/security.txt  

We do **not** publish full internal audit reports by default. If an independent assessment summary is released later, it will be linked from the security page with date and scope.

## App integrity note

Firebase App Check / Play Integrity / App Attest may run in **monitor** mode before enforcement. Monitor ≠ claim that all API abuse is already blocked.
